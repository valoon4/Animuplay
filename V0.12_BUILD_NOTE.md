# v0.12 Build Note

Build command in a normal Android SDK environment:

```bash
./gradlew assembleDebug
```

Expected output:

`app/build/outputs/apk/debug/app-debug.apk`

The project uses the existing `app/debug.keystore` from v0.11 so the resulting v0.12 debug APK is update-compatible with v0.11.

This execution environment could not perform the final Gradle/Android build because Android SDK/Build Tools are not installed locally and outbound Gradle/SDK downloads are blocked. See `QA_REPORT_v0.12.md`.
